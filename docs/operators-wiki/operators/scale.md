# operator: scale

- Category: [Cross Sectional](../categories/cross-sectional.md)
- Scope: REGULAR
- Level: ALL
- Definition: scale(x, scale=1, longscale=1, shortscale=1)
- Documentation: /operators/scale

## Description

Scales input to booksize. We can also scale the long positions and short positions to separate scales by mentioning additional parameters to the operator
