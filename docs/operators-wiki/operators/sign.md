# operator: sign

- Category: [Arithmetic](../categories/arithmetic.md)
- Scope: REGULAR
- Level: ALL
- Definition: sign(x)
- Documentation: /operators/sign

## Description

Returns the sign of a number: +1 for positive, -1 for negative, and 0 for zero. If the input is NaN, returns NaN.<br><br>Input: Value of 7 instruments at day t: (2, -3, 5, 6, 3, NaN, -10)<br>Output: (1, -1, 1, 1, 1, NaN, -1)
